# Costalum — sitio web (prototipo)

Sitio estático en HTML/CSS/JS, sin build. Abre `index.html` en el navegador o sírvelo con cualquier hosting estático (Vercel, Netlify, GitHub Pages).

## Estructura

- `index.html`: página completa (estilos y scripts incluidos).
- `images/`: logo y fotografías tomadas de las publicaciones de @costalum_do.

## Pendiente de confirmar con Costalum

Los campos marcados como `[POR CONFIRMAR]` en el sitio: dirección, zonas de cobertura, horario, correo, años de experiencia, garantía, tiempo de fabricación, métodos de pago, visita técnica, materiales y especificaciones de M100 y P40. Confirmar también que +1 829 727 0751 sea su WhatsApp de atención y reemplazar las imágenes por fotos originales autorizadas.

## Formulario de cotización

Es un prototipo: no envía datos a ningún servidor. Al confirmar arma un resumen y abre WhatsApp con el mensaje listo.
